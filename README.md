# Portfólio Tech | Vitrine Digital

Uma landing page premium desenvolvida com foco em conversao, autoridade e inteligencia de dados. Este projeto vai alem de uma simples apresentacao visual; e uma ferramenta estrategica construida para gerar resultados e otimizar a captação de leads.

## Links Oficiais
- **Deploy ao vivo:** [Acessar o Portfolio](https://portfolio-opal-omega-7kjyjot4r6.vercel.app)

## Tecnologias e Recursos Aplicados

- **UI/UX Avancado:** Design em Dark Mode estruturado para retencao de atencao e conforto visual.
- **Glassmorphism:** Efeito visual moderno e elegante estilo "vidro fosco" utilizando CSS3 puro.
- **Integracao WhatsApp API:** Botoes de Call to Action (CTA) focados na reducao de atrito para o fechamento rapido de propostas.
- **Inteligencia de Dados:** Rastreamento de conversoes implementado via Meta Pixel direto no core da aplicacao, preparando a estrutura para campanhas de trafego pago.

## Estrutura Moderna (Next.js 15)

- **App Router:** Arquitetura moderna do Next.js com App Router para melhor performance.
- **TypeScript:** Tipagem estatica para maior confiabilidade no codigo.
- **Tailwind CSS:** Framework CSS-first para estilizacao rapida e consistencia.
- **next-themes:** Sistema de temas claro/escuro com persistencia.
- **lucide-react:** Icones vetoriais minimalistas para uma interface limpa.

## Acessibilidade (WCAG 2.2)

- **AccessHomeAnalyzer:** Componente exclusivo baseado na pesquisa PICTA 2026 para auditoria em tempo real.
- **Monitor de Foco NVDA:** Acompanhamento da navegação por teclado.
- **Controles de Contraste:** Alto contraste AAA e escala tipografica ajustavel.
- **Auditoria Automatica:** Verificacao de headings, landmarks, atributos alt e muito mais.
